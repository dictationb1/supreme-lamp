පිටුව සහ **වෙබ් අඩවි මූලාශ්‍ර කළමනාකරණය** නැවත ගොඩනඟා ඇත. සම්පූර්ණ ඉංග්‍රීසි
වාර්තාව `README.md` ගොනුවේ ඇත; මෙය එහි කෙටි සාරාංශයයි.

## කලින් තිබූ ගැටලු

1. සෙවුම් කළේ PowerShell සේවාදායකයේ කේතගත කර තිබූ ඉටුකරුවන් පහක් (adapters)
   පමණි. එබැවින් Open Culture, Internet Archive, Openverse, `awesome-*` ලැයිස්තු,
   `fmhy.net`, `rentry.org` යන මූලාශ්‍ර සෙවීමට නොහැකි විය.
2. අලවන ලද URL එකක් සෙවුම් විමසුමක් ලෙස සේවාදායකයට යැවිණි; එය URL පිළිගන්නේ
   නැත. එහෙයින් පොදු (public) GitHub README එකක් සඳහා පවා "මුරපදය අවශ්‍යයි"
   පණිවිඩය පෙන්වුණි.
3. `awesome.re` යනු `sindresorhus/awesome` වෙත යන නිල මාර්ගයයි; එය "hostname
   mismatch" ලෙස වැරදි ලෙස වාර්තා විය.
4. ලැයිස්තුවක් (curated list) "GitHub Releases" මූලාශ්‍රයක් ලෙස සැලකූ අතර,
   නිකුතු නොමැති විට "ප්‍රතිඵල නැත" ලෙස පෙන්වුණි.
5. මූලාශ්‍ර එකතු කළ හැකි වූ නමුත් සංස්කරණය, අක්‍රීය කිරීම, නැවත පරීක්ෂාව,
   ඉවත් කිරීම හෝ export/import නොතිබුණි.
6. එක් මූලාශ්‍රයක් අසාර්ථක වූ විට මුළු තිරයම එක් දෝෂ පණිවිඩයක් බවට පත් විය.

## දැන් කර ඇති දේ

* සියලුම මූලාශ්‍ර **browser එකේ** ක්‍රියාත්මක වන ඉටුකරු එන්ජිමක් මගින් සෙවේ
  (`src/lib/providers/*`). එක් එක් සේවාවට ඇති සැබෑ අතුරුමුහුණත පමණක් භාවිතා කරයි:
  GitHub API, archive.org advancedsearch/metadata, Openverse `/v1/*`,
  Open Culture RSS+sitemap, FMHY sitemap+පිටු, rentry `/raw` Markdown.
* එක් එක් මූලාශ්‍රය සඳහා **වෙන වෙනම තත්ත්වය** පෙන්වයි: සම්පූර්ණ / හිස් /
  අසාර්ථක (හේතුව සමඟ) / අවලංගු කළ. එකක් අසාර්ථක වුවත් අනෙක් ප්‍රතිඵල රැඳේ.
* අලවන ලද URL එකක් පරීක්ෂා කර පෙරදසුනක් පෙන්වයි; **සෙවිය හැකි නම් පමණක්**
  "මූලාශ්‍රයක් ලෙස එකතු කරන්න" ලබා දේ. පොදු GitHub අන්තර්ගතයට මුරපදයක්
  කිසිදා ඉල්ලන්නේ නැත.
* **මූලාශ්‍ර කළමනාකරණය**: URL + නම + සටහන් සමඟ එකතු කිරීම, ස්වයංක්‍රීය වර්ග
  හඳුනාගැනීම, පරීක්ෂාව, ධාරිතා විස්තරය, සක්‍රීය/අක්‍රීය, සංස්කරණය, නැවත
  පරීක්ෂාව, ඉවත් කිරීම, JSON export/import, සහ එකවර URL කිහිපයක් ඇතුළත් කිරීම.
* මූලාශ්‍ර සේවාදායකයේ (`/api/f58/sources`) සුරැකේ; `localStorage` පිටපතක් ද
  තබා ගනී. නව මූලාශ්‍රයක් **නැවත deploy නොකර** සෙවුමේ පෙනේ.
* නව ඉංග්‍රීසි පෙළ සියල්ලට **සිංහල පරිවර්තන** එකතු කර ඇත (සමානාත්මතා පරීක්ෂාව
  සමත්).
